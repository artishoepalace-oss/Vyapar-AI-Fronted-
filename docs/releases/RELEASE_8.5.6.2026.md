# Vyapar AI 8.5.6.2026

## UI motion and Liquid Glass release

- Added smoother directional page transitions across Home, Business, Sales, Stock, More and Settings.
- Added spring-style tab feedback and a smoother moving active navigation glass indicator.
- Improved dark/light theme switching with a non-opaque expanding liquid-lens transition instead of a hard flash.
- Refined iOS-style popup and bottom-sheet entrance motion.
- Added more consistent Apple-like continuous corner radii for cards, controls, headers and sheets.
- Added subtle convex/chromatic liquid-glass edge treatment inspired by the supplied visual reference while keeping text sharp.
- Added Android 8+ adaptive round launcher icon masking to prevent square white icon bleed on OEM launchers.
- Preserved existing app features, business/accounting logic, auth flows and navigation semantics.
- Kept Android 7/8 performance fallbacks for expensive blur effects.
